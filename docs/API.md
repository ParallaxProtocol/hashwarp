# Hashwarp API

Hashwarp serves a web dashboard, a JSON API, Prometheus metrics and a JSON-RPC interface on one TCP
port (`--api-bind`). They are documented on the Parallax documentation site:

* [Dashboard](https://docs.parallaxprotocol.org/hashwarp/dashboard): one rig or all of them,
  `--rig` and `--monitor`
* [API](https://docs.parallaxprotocol.org/hashwarp/api): `/api/v1/summary`, `/api/v1/rigs`,
  `/api/v1/control`, Prometheus metrics and JSON-RPC
